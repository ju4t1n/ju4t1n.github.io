# Chengxin Shi — Academic Homepage

A static, English-language academic homepage with a restrained blue palette and a simple research-profile layout. It uses HTML, CSS, and a small JavaScript file for the competition-video speed controls; no build step is required.

## Preview locally

Open `index.html` in a browser.

## Sections

- Short Bio
- Research in Progress
- Publications & Manuscripts
- Competitions & Project Experience
- Honors & Interests

## Update personal content

- Edit `index.html` to update profile details, research, papers, experience, honors, and contact information.
- Replace `assets/profile-photo.jpg` with another portrait if desired.
- Award scans are in `assets/awards/`; clicking a certificate thumbnail opens the full image.
- Research diagrams are in `assets/paper/`; the Smart City competition video and playback controls are in `assets/competition/`.

## Before publishing

Review paper titles, author order, venues, and statuses against the latest CV. The page has no analytics, embedded services, or GitHub Pages workflow.
